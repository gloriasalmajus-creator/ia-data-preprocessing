# Pipeline de Pré-processamento de Dados para IA 🤖📊

Este repositório contém um projeto prático focado em uma das etapas mais críticas da Engenharia de Inteligência Artificial: o **Pré-processamento e Limpeza de Dados**. 

Antes que qualquer modelo de Machine Learning ou IA possa aprender, os dados brutos precisam ser validados, limpos e padronizados para evitar vieses e erros de processamento.

## 🚀 Objetivo do Projeto
Desenvolver um script em Python focado em simular uma esteira de dados (data pipeline) automatizada que recebe registros inconsistentes e realiza:
- **Tratamento de Strings:** Remoção de espaços em branco residuais (`.strip()`) e padronização de caracteres (`.title()`, `.lower()`).
- **Tratamento de Tipagem e Anomalias:** Conversão de dados textuais para numéricos com tratamento de exceções (`try/except`) para evitar a quebra do sistema de IA.
- **Validação de Regras de Negócio:** Filtros lógicos para identificar dados ausentes ou estruturalmente incorretos.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** Python 3
- **Conceitos:** Funções, Tratamento de Erros, Manipulação de Strings e Lógica Condicional.

## 📈 Evolução Futura
Conforme o avanço nas disciplinas de Ciência de Dados do 2º período, este pipeline será integrado com as bibliotecas `Pandas` e `NumPy` para manipulação de grandes volumes de dados (Dataframes) e exportação automatizada para bancos de dados SQL.
